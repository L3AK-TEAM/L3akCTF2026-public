# Relizane is Down!
### Author: Houssem0x1
What started as an employee casually browsing the web quickly turned into a full-scale compromise. The machine began behaving abnormally, yet the victim claims he never downloaded or executed anything suspicious.
The incident response team contained the threat before it could spread further, but the attacker was careful. Stealth, evasion, and anti-forensics techniques were used to erase evidence and mislead investigators.
The system may be silent now, but it still has a story to tell. Investigate the compromised machine, reconstruct the attacker’s actions, and uncover what really brought Relizane down.
